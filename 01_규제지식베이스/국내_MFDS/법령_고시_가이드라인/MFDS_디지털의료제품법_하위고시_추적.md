# MFDS 디지털의료제품법 하위 고시·가이드라인 추적 리스트

> **디지털의료제품법**: 2025-01-24 시행. 기존 의료기기법과 병행 적용. AI·SaMD 중심 디지털의료기기를 별도 법체계로 규율.

### 0-1. 2026-01-24 시행 조항 (분기#2 추가, 발효 완료)
시행령 일부 조항(제3조제2항제3호·제3조제5항제8호·제6조제2항제2호·제8조제10호·제8조제11호)은 1년 유예 후 **2026-01-24부**로 시행됨. 핵심은 **전자적 표시기재 제도** — 디지털의료기기 SW 화면·QR·전자바코드·UI·앱·홈페이지·이메일 등을 통한 정보제공 방식 도입. AI 디지털의료기기는 학습데이터 출처·시점, 예측 성능·한계, 업데이트 이력 투명 공개 의무. 시행규칙 일부도 같은 날 시행되어 **자율성능인증제** 운영 개시. 출처: 디지털의료제품법 시행령 개정문(law.go.kr), MFDS 2026 업무보고(2025-12-16).

> 자사 영향: GUI SW가 디지털의료기기로 분류될 경우 **2026-01-24부 전자적 표시기재 의무**. AI 미탑재면 학습데이터 공개 의무는 무관. 결합형(X-ray 본체+SW 일체) 판정 시 내장형 표시기재 요건 적용.

### 1-1. 고시 제2026-54호 일부개정 (2026-07-27 발령·시행) ★주간모니터 #14 신규 감지★

> 출처(1차): 국가법령정보센터 행정규칙 상세 — 행정규칙ID 92599 / 일련번호 2100000283212. 발령·시행 2026-07-27(고시한 날부터 시행). 소관: 식약처 디지털의료제품지원총괄과.

**사실 (Fact)** — 개정이유·주요내용 원문 요지

- 개정이유: 「디지털의료제품법」 시행(2025-01-24) 이후 허가·인증 및 심사 현황을 고려해 **디지털의료기기 임상시험 등 평가 제출자료 요건을 합리적으로 개선**하고, 같은 법 시행규칙 개정(2026-01-23)으로 **상향 입법된 조문을 정비**.
- 가. **제7조 등** — 시행규칙 상향 입법에 따라 디지털의료기기소프트웨어의 **중요한 변경 사항**과 **AI 적용 SW 정보 표시 항목**을 고시에서 **삭제**(근거가 시행규칙으로 이동).
- 나. **제25조** — 기능별 임상시험 등 평가자료의 **제출 면제·대체 요건**을, 종전 "정보제공·관리 등의 분야 또는 2등급 독립형 SW" 한정에서 **등급과 무관하게 치료·진단·검사 등 전 분야로 확대**.
- 다. **제25조·제28조** — **우수관리체계 특례** 대상을 2등급 독립형 SW → **2등급 및 등급 미지정 독립형 SW**로 확대. 허가 후 **실사용평가결과보고서** 제출기한을 "허가 후 3년의 범위에서 실사용평가가 종료되는 날부터 30일 이내"로 **연장**.
- 라. **제31조·제31조의2 신설** — 디지털의료·건강지원기기 **성능인증 정보 공개** 항목 신설, 성능인증업무 대행기관이 발급하는 **성능인증서 서식** 명확화.
- 부칙 <제2026-54호, 2026-07-27>: 제1조 시행일(고시한 날), 제2조 기술문서심사 결과통지서 경과조치, 제3조 일반적 경과조치.

**해석 (Interpretation)**

- 영향 제품: **P3 촬영실 GUI SW**(디지털의료기기소프트웨어에 해당하는 경우). P1 X-ray Detector·P2 Handheld X-ray Source는 의료기기법 체계 적용으로 **직접 영향 없음**(§3·§4 매트릭스 유지).
- 나항은 자사에 **유리한 완화**다. GUI SW가 2등급이든 등급 미지정이든 기능별 임상시험 자료의 **면제·대체 경로가 열린다**. 다만 면제·대체의 개별 요건(개정 제25조 각 호)은 조문 전문 확인이 필요하다 — `[검증 필요]`.
- 가항은 요건의 삭제가 아니라 **근거 조문의 이동(고시 → 시행규칙)** 이다. 「디지털의료제품법 시행규칙」(2026-01-23 개정)의 해당 조문을 확인해야 실제 의무 범위를 알 수 있다 — `[검증 필요]`.
- 다항의 우수관리체계 특례는 **QMS 성숙도를 인허가 편익으로 전환**하는 제도다. KGMP·ISO 13485 기반이 갖춰진 경우 중장기 활용 가치가 있다.

**행동 (Action)**

1. **GUI SW의 디지털의료기기 해당 여부 판정을 선행**한다(「디지털의료제품 분류 및 등급 지정 등에 관한 규정」 고시 제2026-4호). 해당하지 않으면 본 개정의 실익은 없다.
2. 개정 **제25조 전문**을 입수해 기능별 임상평가 자료의 면제·대체 요건을 조문 단위로 매핑 → 분기 심층패치 과제.
3. 「디지털의료제품법 시행규칙」(2026-01-23 개정) 중 **중요한 변경·AI 정보표시** 상향 조문을 확인해 §0-1(전자적 표시기재)과 정합화 → 분기 심층패치 과제.
4. **우수관리체계 특례** 적용 가능성을 착수준비 트래커의 MFDS 게이트에 선택지로 기록(현 단계에서 의사결정 사항 아님).

### 2-1. 2025-10-31 임상시험 가이드라인 9종 개정 (분기#2 추가)
식약처는 디지털의료제품법 하위 규정 시행 후속으로 임상시험 가이드라인 9종을 전면 개정. AI 디지털의료기기 7종(관상동맥협착·대장암·알츠하이머성 치매·유방암·전립선암·폐암/폐결절·허혈성뇌졸중) + 디지털치료기기 2종(임상시험 설계·불면증 개선). 핵심 변경: AI 추가 사용군 vs 임상의 단독진단군 **비교설계**, 분석적 임상정확도 제시, 적응증별 유효성 평가지표 예시, 전향적 임상 원칙 명확화, 효과 크기 입증·탈락률 관리 실무지침 추가.
- 자사 영향: 자사 GUI SW가 AI 보조 기능 탑재 시 임상시험 설계 직접 영향. 현재 미탑재이나 향후 AI 모듈 추가 가능성 고려해 비교설계 원칙 사전 학습 권고.
- 출처: 정책브리핑 2025-10-31(https://www.korea.kr/briefing/pressReleaseView.do?newsId=156724315)

## 3. 기존 의료기기법 체계와의 관계

| 항목 | 의료기기법 체계 | 디지털의료제품법 체계 |
|---|---|---|
| 적용 대상 | 전통 의료기기 (하드웨어 중심) | AI·SaMD·디지털의료기기 |
| X-ray Detector | **의료기기법** 적용 | 해당 없음 (HW 중심) |
| Handheld X-ray Source | **의료기기법** 적용 | 해당 없음 |
| 촬영실 GUI SW | 부속SW → 의료기기법 | 독립SW·AI 기능 시 **디지털의료제품법** 검토 |

> **판단 포인트**: GUI SW가 하드웨어(X-ray System)에 종속된 부속 SW인지, 독립형 SaMD인지에 따라 적용 법률 분기. 2025-05-07 신규 가이드라인의 판단 흐름도 참조 필수.

1. SW가 독립적으로 의료행위를 지원하는가? → Yes → SaMD 검토
2. AI/ML 기능을 포함하는가? → Yes → 디지털의료제품법 적용 가능
3. HW에 종속된 부속 SW인가? → Yes → 의료기기법 기준 부속 SW로 처리
