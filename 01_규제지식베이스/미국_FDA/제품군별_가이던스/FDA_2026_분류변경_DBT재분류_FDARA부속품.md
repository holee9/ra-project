## 2. Interpretation

| 쟁점 | 판단 |
|---|---|
| #117 자사 해당성 | Part 892(방사선) 항목 **0건** → P1/P2/P3 부속품(검출기 충전기·배터리·케이블 등) **비해당**. 종전 "radiology 부속품 포함 여부 확인" 후속 폐쇄 가능. |
| #117 선제기회 | FR §III에 따라 의견으로 **추가 부속품 제안 가능**(product code·분류규정·일반통제 충분 근거 제시). 단 P1 무선검출기 충전기 등은 device-specific·SW 연동 성격이 강해 적격 개연성 낮음 [해석]. |
| #116 자사 해당성 | OTE는 **완제 시스템** 분류. P1이 범용 DR 검출기(MQB)인 한 직접 비해당. P1을 DBT 제조사에 **OEM 수상체로 공급**할 경우 해당 제조사 510(k)에 **IEC 62220-1-2 DQE·Detector Lag** 데이터 제공 요구가 발생할 수 있음 [해석]. |
| #116 P2/P3 | P2(핸드헬드 X선원)는 유방용 아님 → 비해당. P3 GUI SW가 DBT 재구성·과제기반 평가 기능이 없는 한 비해당. |
| #116 전략적 의미 | PMA→510(k) 전환으로 DBT 시장 진입장벽 하락. in silico 평가 허용은 FDA의 CM&S 신뢰성 가이던스(2023) 활용 확대 신호 [해석]. |
